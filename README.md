## Studio・PlotLauncherと一つの画面で編集

[Figure Studio統合画面](https://murajun620-crypto.github.io/plot_launcher_web/figure-studio/)のMiFiToタブで画像を編集し、トップバーからStudioへ送ります。受信完了後はStudioタブへ自動で戻ります。Studioの画像をダブルクリックすればMiFiToの対象画像へ戻り、一度開いた画面はタブ切替で再読み込みしません。

MiFiToの単独URLも維持し、単独起動時はStudio送信ボタンを表示しません。統合画面は単独版と同じHTML・JavaScriptを読み込み、編集機能を複製しません。[Studio単独](https://murajun620-crypto.github.io/plot_launcher_web/figure-studio/studio.html)から編集する場合は、同じ配信元の既存編集タブを再利用します。別の内容や未反映の編集を勝手に置き換えません。統合作業の一括保存はFigure Studio v0.5.0・PlotLauncher v2.4.21・MiFiTo v1.9.5以降に対応します。

統合画面の保存では、Studioの全Figureと、PlotLauncher・MiFiToで開いている最新の編集状態を一つの `.figurestudio` ファイルに保存します。Studioへ未反映の画像・設定、確定前の入力内容、選択中の画像とUndo履歴も含みます。開き直すと各編集画面へ復元し、未反映の変更はStudioへ自動反映しません。数値欄がブラウザーで解釈できない入力途中の状態なら、確定するか空欄にしてから保存します。

初回はフォルダーとファイル名を選び、次回から同じ統合ファイルへ上書きします。保存ボタン右のメニューに「名前を付けて保存」があります。統合保存によって個別の `.mifito` ファイルは上書きされません。個別ファイルも更新したい場合は、MiFiTo側のプロジェクト保存を使ってください。

別のMiFiToプロジェクトを開いたときは、前の図への接続と送信待ちデータを解除します。続けて「送る」を使うと、新しいプロジェクトの画像を追加・更新し、前のプロジェクトの図は維持します。読み込みの失敗・キャンセル時は、元の内容と関連付けを保ちます。

## Figure Studioへまとめて反映

統合画面のトップバーにある「まとめてStudioへ送る」で、開いている画像をFigure Studioへ一括追加・更新できます。表示中の1枚だけを送る場合は「Figure Studioへ送る」を使います。Studioの図から開いた場合も同じボタンを使い、関連付けた元の画像を更新します。接続状態や処理結果もヘッダー内に表示し、画像・表を操作しながら確認できます。

プロジェクト・画像ごとの識別情報を `.mifito` に保存するため、画像を並べ替えたりプロジェクトを開き直したりしても対応が維持されます。変更した画像だけを更新し、変更のないプレビューはスキップします。既に複数のFigureへ配置した画像は位置を保ち、未追加の画像は受信先で開いているFigure（連携編集時は元のFigure）へ追加します。更新・追加・変更なしの枚数を表示し、StudioのCtrl+Zで一括変更を1回で戻せます。MiFiToから画像を削除しても、Studio上の画像は自動削除しません。Figure Studio v0.4.0以降と組み合わせて利用してください。

プレビュー上の「Studioに貼る画像サイズ」は、新規画像ではサイズ指定オン・高さ40 mm・「全画像に適用」オンが初期値です。幅または高さを0.1〜1000 mmで指定でき、「全画像に適用」がオンなら変更時に全画像をまとめて更新します。オフなら表示中の画像だけを変更します。既存プロジェクトや設定ファイルの保存済み寸法はそのまま復元します。カラーバーや画像外のラベル領域を含まない画像本体の寸法で、縦横比を維持します。単体送信・一括送信の両方に対応し、通常のファイル保存の寸法は変えません。

Figure Studio v0.7.10以降では、再送信時もMiFiToで明示した画像本体サイズを優先します。Studio上で手動変更した倍率は掛け直さず、配置位置を維持して指定寸法へ更新します。画像外のラベル・カラーバーはその寸法に含みません。
